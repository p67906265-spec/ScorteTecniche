# Scorte Tecniche

Android app per il sito https://scortetecniche.rf.gd

Versione iniziale: 1.0
Application ID: it.paolo.scortetecniche

L'app mantiene la sessione, permette il caricamento di file e scarica PDF e documenti nella cartella Download. La ruota delle impostazioni consente di cambiare l'indirizzo del sito senza reinstallare l'app.

Il workflow GitHub Actions genera automaticamente l'APK installabile `ScorteTecniche-v1.1-apk`.
